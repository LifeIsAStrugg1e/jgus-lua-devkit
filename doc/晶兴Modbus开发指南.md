# 晶兴 Modbus 开发指南（屏幕侧）

> **来源**：整理自《晶兴Modbus开发指南V1.0》（深圳市晶兴科技，2015-08-30，6 页）
> **PDF 原文**：`晶兴Modbus开发指南V1.0.pdf`（同目录；其中"Modbus 快捷配置"工具界面为截图，无法提取，以文字+参数表描述为准）

## 0. 本文定位：哪条 Modbus 路

晶兴屏幕有**两条完全独立的 Modbus 路径**，别混淆：

| | **屏幕侧 Modbus（本文）** | **Lua 侧 Modbus（本项目用的）** |
|---|---|---|
| 谁发 Modbus 帧 | **屏幕自己**（固件按 22.BIN 配置自动收发） | 主控模组 Lua 代码（`modbus.lua`） |
| 配置方式 | 上位机"Modbus 快捷配置"生成 22.BIN，SD 卡下载 | 改 Lua 代码：`modbus.sendModbusCommand()` |
| Lua 的角色 | 不参与；屏幕直连外设，数据自动落到屏幕 VP | 帧的组帧/收帧/校验全在 Lua |
| 数据落点 | 屏幕数据存储区（VP），绑定的控件直接显示 | Lua 变量，再 `vp_write` 给屏幕显示 |
| 适用场景 | 屏幕直连 Modbus 设备（PLC/IO 模块），**省掉主控转发** | 主控还要做业务逻辑/多协议/复杂状态机（本项目：只发不收遥测 + 倒计时引擎） |

本项目串口只连屏幕、外设走自定义 ASCII 上报，**没用屏幕侧 Modbus**；将来若"屏幕直连从站、主控只管屏幕"，可走本文这条路。

## 1. 通用 Modbus 协议帧

```
| 地址域 (1B) | 功能码 (1B) | 数据 (N B, N<254 且 N≠0) | 差错校验 CRC-16 (2B) |
```

- **PDU**（协议数据单元）：最大 253 字节
- **ADU**（应用数据单元）：最大 256 字节
- 地址域：Modbus 设备地址 1 字节
- 功能码：通知设备执行哪种操作，1 字节
- 差错校验：CRC-16，2 字节

## 2. Modbus 配置（22.BIN）

### 2.0 字/字节换算（先记住这个坑）

**屏幕以字（Word）为单位，每个地址对应 2 字节；BIN 文件以字节为单位**——所以：

```
屏幕地址 0x5000  ↔  22.BIN 文件地址 0xA000
（BIN 地址 = 屏幕地址 × 2 + 0x5000）
```

下文所有地址均指**屏幕数据存储器地址**（用上位机快捷配置工具时直接填屏幕地址）。

### 2.1 Modbus 全局配置（0x5000~0x5007）

| 地址 | 功能 | 说明 |
|---|---|---|
| 0x5000 | Modbus 启用标志 | `0x5AA5`=启用；其他值=关闭 |
| 0x5001:H | 保存配置文件标志 | `0x5A`=保存 Modbus 配置信息到 22.BIN，保存完成后该位**自动清除** |
| 0x5001:L | 加载配置文件标志 | `0x5A`=从 22.BIN 加载 Modbus 配置信息，加载完成后该位**自动清除** |
| 0x5002 | 串口波特率 | 单位 **0.1kbps**，最大 999.9kbps。例：`9.6`=9600、`19.2`=19200、`115.2`=115200 |
| 0x5003:H | 串口工作模式 | `0x00`=8N1；`0x01`=8E1（偶校验）；`0x02`=8O1（奇校验）；`0x03`=8N2 |
| 0x5003:L | 保留 | 不用操作 |
| 0x5004:H | 保存变量标志 | `0x5A`=保存数据存储区内容至 22.BIN（起止地址由 0x5005 指定），完成后**自动清零** |
| 0x5004:L | 读取 22.BIN 标志 | `0x5A`=读取 22.BIN 指定地址内容到数据存储器（起止地址由 0x5005 指定），完成后**自动清零** |
| 0x5005 | 数据读写起止地址 | H=高地址；L=低地址（**低字节强制为 0**）。例：`0x0312` = 对 0x0300~0x1200 做读/写；仅在 0x5004 配置有效时起作用 |
| 0x5006~0x5007 | 保留 | 不用操作 |

### 2.2 Modbus 指令配置（0x5008~0x6FFF，最多 1023 条）

指令配置在 22.BIN 的 0xA010~0xDFFF（对应屏幕 0x5008~0x6FFF）。**每条指令占 8 个字（16 字节）**，从 0x5008 起顺序排列，第 n 条基址 = `0x5008 + (n-1)*8`，直到第 1023 条（0x6FF8~0x6FFF）。

每条指令 8 个字的含义：

| 字内偏移 | 功能 | 说明 |
|---|---|---|
| +0 H | Modbus 启用标志 | `0x5A`=启用本条指令；其他=不启用 |
| +0 L | Modbus 设备地址 | 本条指令对应的从站地址 |
| +1 H | Modbus 功能码 | 本条指令对应的功能码（见第 3 节） |
| +1 L | 读写数据长度 | 设置读写数据的长度，**0x00 无效** |
| +2 | 发送/响应时间 | 单位 ms，最大 9999ms |
| +3 H（0x500B） | 指令发送方式 | `0`=**任意页面**都执行本条指令（0x500C 不用配）；`1`=在 0x500C 指定的**页面**执行；`2`=在 0x500C 指定的**变量地址低字节为 0x5A** 时执行（如 0x500C=0x0120，则存储区 0x0120 低字节=0x5A 时触发） |
| +3 L（0x500C） | 发送方式参数 | 见上一行（页面号或触发变量地址） |
| +4（0x500D） | 读写数据在 AGUS 数据存储区的起始地址 | 例：写 0x0010，则读指令收到的数据存入以 0x0010 起始的存储区（屏幕数据变量显示控件绑 0x0010 即自动显示）；写指令则把 0x0010 起始的内容发到 Modbus 寄存器（地址由 0x500E 指定）。**数据长度要一致！** |
| +5（0x500E） | 读写 Modbus 设备寄存器的起始地址 | Modbus 侧寄存器起始地址 |
| +6（0x500F） | 保留 | 不用操作 |

**曲线缓冲区特殊写法**（0x500D 高字节 = 0xFF 时）：表示把数据写入 AGUS **曲线缓冲区**，低字节表示曲线通道位掩码（共 8 个通道，每位一个通道）：

| 写法 | 含义 |
|---|---|
| `(0x500D) = 0xFF04` | 写入曲线第 **3** 通道（bit2） |
| `(0x500D) = 0xFF20` | 写入曲线第 **6** 通道（bit5） |

### 2.3 配置操作流程

1. 打开 **AGUS_Design**，菜单栏 **工具 → Modbus 快捷配置**
2. 点击 **导入**，把 `22_Config.bin` 导入软件，在表格里设置各条指令参数
3. 点击 **生成配置文件**，把 `22_Config.bin` 拷贝至 SD 卡，下载至屏幕

### 2.4 配置参考实例

**需求**：
- 设备 01H：读寄存器 0000H/0001H/0002H（各 2 字节），结果显示在屏幕数据存储区 0100H/0200H/0300H
- 设备 02H：把屏幕存储区 0003H 的内容写入 Modbus 寄存器 0012H

**配置**（指令表填法）：

| 条 | 启用 | 设备地址 | 功能码 | 长度 | 超时 | 发送方式 | 屏幕存储区起始 | Modbus 寄存器起始 |
|---|---|---|---|---|---|---|---|---|
| 1 | 0x5A | 01 | 0x03（读保持寄存器） | 2 | ≤9999ms | 0（任意页） | 0x0100 | 0x0000 |
| 2 | 0x5A | 01 | 0x03 | 2 | ≤9999ms | 0 | 0x0200 | 0x0001 |
| 3 | 0x5A | 01 | 0x03 | 2 | ≤9999ms | 0 | 0x0300 | 0x0002 |
| 4 | 0x5A | 02 | 0x06（预置单寄存器） | 2 | ≤9999ms | 0 | 0x0003 | 0x0012 |

屏幕侧数据变量显示控件分别绑 0x0100/0x0200/0x0300；写方向则在屏幕上放个输入/调节控件绑 0x0003。

## 3. AGUS 支持的 Modbus 功能码

| 功能码 | 功能 | 读写数据长度 | Modbus 起始地址含义 |
|---|---|---|---|
| 0x01 | 读取输入线圈状态 | 线圈个数 / 8 | 起始线圈位置 |
| 0x02 | 读取输入位变量状态 | 位变量个数 / 8 | 起始输出位置 |
| 0x03 | 读取保持寄存器数据 | 寄存器个数 × 2 | 保持寄存器首地址 |
| 0x04 | 读取输入寄存器数据 | 寄存器个数 × 2 | 输入寄存器首地址 |
| 0x05 | 强置单个线圈 | 0x02 | 线圈地址 |
| 0x06 | 预置单个寄存器 | 0x02 | 寄存器地址 |
| 0x07 | 读取异常状态 | 0x01 | 任意值 |
| 0x0F | 强置多个线圈 | 线圈数量 | 起始线圈位置 |
| 0x10 | 预置多个寄存器 | 寄存器个数 × 2 | 寄存器首地址 |
| 0x11 | 读取从机标示 | 从机标示字节数 | 任意值 |

**长度规则**：寄存器类（0x03/0x04/0x10）按"寄存器个数×2"填字节数；线圈类（0x01/0x02）按"个数/8"填；单点写（0x05/0x06）固定填 2。

## 4. 与本项目的关系

- 本项目串口只连屏幕、外设通信走 Lua `uart.send` 自定义 ASCII（"只发不收"），**没有用屏幕侧 Modbus**，`jgus.disable_serial_receive()` 也未启用——两条路互不影响
- 若将来改为屏幕直连 Modbus 从站（如 IO 模块），可用本文配置 22.BIN，把从站数据直接落到 VP、控件自动显示，**省掉 Lua 转发环节**；此时若 Lua 还要干预，需评估串口占用冲突
- Lua 侧 Modbus（组帧/收帧/CRC/状态机）见 `JGUS开发手册.md` 附录 C"Modbus 帧速查"与 `modbus.lua`
