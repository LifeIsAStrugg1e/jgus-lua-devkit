# jgus-lua-devkit

JGUS 串口屏 + Lua 主控模组的个人开发套件——**代码块库 + 可跑工程模板 + 整理过的开发文档**,用于新串口屏 Lua 项目的快速启动。

> 适用:基于晶兴 JGUSII 系列串口屏 + 带 Lua 运行时的主控模组做二次开发;自定义串口协议(A5 5A 帧头 + CRC16)、触控按键轮询、页面管理、倒计时引擎等常见需求开箱即用。

## 为什么有这个仓库

把分散在多个项目里的经验沉淀成一个"下次开工直接抄"的地方:

- **代码块库**:20 个与具体工程无关的可复用模式(占位符版),每块附「能做什么/怎么用/依赖/要改什么」说明卡;
- **工程模板**:一个完整可跑的 `main.lua` 实例(已验证),带 VP 地址映射表和新工程适配清单;
- **文档**:从厂商手册 + 实战项目整理出的开发手册,含坑位记录。

## 快速开始(新工程三步)

1. **复制 `doc/工程模板.lua` 为新工程的 `main.lua`**——它是验证过的完整实例;
2. **对照模板文件头部的 VP 映射表 + 文件末尾适配清单**,替换 VP 地址、页面号、协议字段;
3. **单块细节查 `doc/代码块库.md`**:每块都有"能做什么/怎么用/依赖/要改什么",从第零部分的使用指南进入。

## 文档维护

`doc/JGUS开发手册.md` 是唯一编辑源。改完后在 `doc/` 目录运行同步脚本,重新生成 AI 阅读用的纯文本镜像(该镜像不入库,克隆后可再生):

```powershell
powershell -ExecutionPolicy Bypass -File make_ai_txt.ps1
```

## 环境要求

- 晶兴 JGUSII 串口屏 + 带 Lua 5.4 运行时的主控模组
- 上位机:串口助手(8N1,默认 115200)
- 文档同步:Windows PowerShell(仅 doc 维护时需要)
